# Arsenal Roadmap

Arsenal's active capability-system roadmap has already delivered major slices including public/distribution work, Capability Contract v2, and Bench v0. It identifies the Knowledge Plane as the current frontier and contains later observability/trust/routing work.

## NOW

- machine-readable capability contracts and initial capability set;
- Repository Truth distribution/compiler path;
- Bench v0 with case-health/counterfactual/lifecycle evidence machinery;
- 19-case evaluation corpus with explicit designed-not-run arms;
- knowledge/trust structures present in the current tree and covered by root Arsenal gates.

## NEXT for the Invariant system

**Milestone:** supply bounded reusable method/review context and qualification evidence to Development Loop v0 without becoming runtime authority.

**Prerequisites:** accepted runtime review/observation shapes from the owning integration work.

**Acceptance property:** Arsenal-derived material can inform the loop while every authority/effect decision remains outside Arsenal.

**Evidence required:** capability identity/provenance, exact exported method/context, Bench claim scope, consumer integration tests.

## LATER

- deepen Knowledge Plane/observability/trust work according to Arsenal's own accepted program;
- controlled model/harness campaigns that execute currently designed-not-run arms;
- evidence-based routing inputs once enough qualification evidence exists.

## FRONTIER

Third-party competence audits, longitudinal flight-recorder analysis, and broad evidence-based model routing remain useful directions. None authorizes Manifold runtime or Kiln execution changes.
