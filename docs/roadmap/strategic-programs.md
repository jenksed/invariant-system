# Strategic Programs

Strategic programs may accelerate the product roadmap, impose comparative targets, or prioritize experiments. They do not replace durable product ownership, architecture, or evidence requirements.

## T3 Challenge / 30-day competitive program

The T3 Challenge is a protected strategic program. Its records should remain historically intact when they enter or are cross-linked from this documentation branch.

Relationship:

```text
Invariant product roadmap
        │
        ├── durable product capabilities
        │     ├── Kiln
        │     ├── Temper
        │     ├── Loadout
        │     ├── Manifold
        │     ├── Bench
        │     └── Arsenal
        │
        └── strategic programs
              └── T3 Challenge / 30-day competitive program
```

Workbench, remote operation, model/provider work, Arsenal archaeology, and other capabilities may satisfy or accelerate T3 targets. That does not turn those capabilities into T3-only work.

### Preservation rule

When T3 program artifacts are available in the repository state being documented:

- preserve them by default;
- cross-link from current roadmap/product pages rather than rewriting the program record;
- keep failed, incomplete, superseded, and negative findings visible;
- never convert a competitive target into an implemented-product claim without current evidence;
- require explicit authorization before editing a protected T3 record itself.

The current documentation branch does not contain the newer T3 program artifacts described by the active engineering process, so this page deliberately does not invent file paths to them. Add exact links when those records are promoted into an inspectable repository state.
