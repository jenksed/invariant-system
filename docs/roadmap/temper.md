# Temper Roadmap

## NOW

Temper truthfully projects real Plan/Run Result data and repository currentness from a read-only terminal workbench.

## NEXT

**Milestone:** project Development Loop v0's proposal, verification, review, and human-decision state without inventing missing facts.

**Prerequisites:** owning runtime/contracts must expose those facts first.

**Acceptance property:** every visible state traces to an accepted source; unsupported facts render absent/unknown; an operator interaction cannot mutate canonical state by writing Temper-local truth.

**Evidence required:** field-level source map, projection tests, missing/stale/contradictory input cases, responsive terminal behavior.

## LATER

Interactive accept/revise/navigation can be added by delegating commands/decisions to the owning authority API or CLI. The UX may initiate an action; Temper must not become the durable decision owner.
