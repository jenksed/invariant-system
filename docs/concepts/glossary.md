# Glossary

**Arsenal** — reusable engineering intelligence, methods, learning, and qualification-related material.

**Bench** — Arsenal's evaluation/qualification evidence domain at `products/arsenal/evaluation`.

**Capability** — a stable user/system-level ability or method packaging. Capability does not imply permission.

**Evidence** — state- and scope-bound support for a claim.

**Kiln** — runtime authority, execution truth, effects, artifacts, evidence, registered verification, and acceptance truth.

**Loadout** — goals, capabilities, planning, configuration, and Work Envelope preparation.

**Manifold** — planned intelligence selection/allocation domain. Boundary only today.

**Plan** — Loadout's prepared description of how a goal should be attempted; not runtime authority.

**Qualified Method Record (QMR)** — cross-product record describing qualified method evidence/provenance.

**Run** — Kiln's durable execution/coordination attempt; not a persona, transcript, branch, or tool call.

**Run Result Envelope** — canonical cross-product projection of a Kiln run result.

**Temper** — read-only operator projection over accepted plan/run-result facts.

**Work Envelope** — canonical cross-product request prepared for execution supervision.
