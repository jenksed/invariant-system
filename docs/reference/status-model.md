# Documentation Status Model

| Label | Meaning |
| --- | --- |
| `current` | implemented or normative now |
| `partial` | a real slice exists but broader capability is incomplete |
| `experimental` | exercisable with deliberately limited maturity/evidence |
| `planned` | bounded direction, not implemented |
| `frontier` | research direction without implementation commitment |
| `historical` | provenance, not current behavior |

The label scopes the page, not every historical reference inside it.
