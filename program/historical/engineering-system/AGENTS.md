# Program Agent Instructions

## Scope

This repository coordinates Arsenal, Loadout, and Kiln. It does not grant authority to change any product repository.

## Product boundaries

- Arsenal owns Engineering Intelligence, experimental methods, evaluation, qualification, Claims, and Proof Obligation design.
- Loadout owns the human-facing capability experience and compiles Goals into Work Envelopes.
- Kiln owns runtime authority, Runs, effects, evidence, currentness, recovery, and acceptance readiness.
- Git and the filesystem remain the source of repository content truth.
- A package may request runtime authority; it cannot grant it.
- Kiln may establish evidence-backed gate state; it does not own human product acceptance.

## Required operating rules

1. One writing agent per product repository at launch.
2. Every task starts from an explicit repository and commit SHA.
3. Every task declares owned paths, prohibited changes, dependencies, verification, and closeout evidence.
4. Shared concepts cross repositories through versioned envelopes or records, never a shared mutable database.
5. Do not make one product import another product's internal ontology.
6. Do not widen Kiln P1-S02-T01 or interrupt its authorized implementation.
7. Do not move broad Project Intelligence into Kiln.
8. Do not make Loadout packages or connectors runtime authority issuers.
9. Do not promote experimental Arsenal material without qualification evidence and an explicit destination decision.
10. Derived status must be generated from repository and issue state; do not maintain competing narrative truth.

## Owner decision required

Stop and request owner adjudication before:

- changing a product's mission or semantic ownership;
- changing a cross-product contract incompatibly;
- granting new runtime authority;
- widening an accepted/authorized work package;
- merging or closing another agent's pull request;
- deleting or rewriting historical evidence;
- introducing a new product, shared runtime, or cross-product database;
- changing the public product names or company positioning.

## Closeout

Every implementing agent must report:

- starting and ending commit SHA;
- changed files;
- verification commands and results;
- contract versions consumed or produced;
- decisions made within authorized discretion;
- assumptions, unknowns, and negative knowledge;
- follow-up work without self-authorizing it.
