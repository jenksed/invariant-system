# Re-Pitch With Missing Context

Use when the user says the prior explanation did not land.

Do not merely repeat or lengthen it.

1. Identify the specific concept or transition that was assumed but not explained.
2. Re-establish only the minimum context needed for that point.
3. Use the project's canonical domain language when available; define any term the user may not share.
4. Prefer short concrete sentences and an example over additional abstraction.
5. State where this fits in the larger workflow/design.
6. Ask whether the re-pitch resolved the confusion before moving on.

The goal is restored shared understanding, not a more verbose version of the same message.
