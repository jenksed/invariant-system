# Prompt Generation Brief

## Purpose

Create a reusable prompt that designs a complete technical learning session around one achievable capability.

## Required behavior

Define one concrete learning objective, identify prerequisites, create a useful mental model and motivating practical scenario, sequence explanation/prediction/action/failure/diagnosis/recovery, include an intentional mistake, require reflection, define observable mastery, and prepare the next logical session.

## Inputs

Topic, learner background, session duration, technical environment, desired practical outcome, prior sessions, and available tools.

## Outputs

Objective, prerequisite check, lesson sequence, instructor guidance, exercises, expected observations, common misconceptions, debugging scenario, mastery assessment, and follow-up work.

## Safeguards

Do not cover an entire technology in one session, equate completed commands with understanding, create copy-only exercises, omit failure/debugging, or overload the learner with terminology.

## Sol optimization

Emphasize runnable environments, code, commands, tests, technical progression, and observable implementation evidence.

## Fable optimization

Emphasize instructional flow, concept sequencing, approachable framing, examples, diagrams, pacing, and learner engagement.
