# Prompt Generation Brief

## Purpose

Create a reusable prompt that turns a technical skill into a realistic, buildable lab that produces verifiable portfolio evidence and interview stories.

## Required behavior

Define the capability being demonstrated; create a realistic operating scenario; define environment/prerequisites; introduce intentional failure; require evidence collection and hypothesis-driven diagnosis; require safe remediation, rollback, or recovery; require validation and receipts; define repository structure/documentation; explain honest interview representation; include logical extensions without bloating the initial lab.

## Inputs

Skill, current ability, available tools, time, target job types, desired portfolio form, existing repositories, and cost constraints.

## Outputs

Lab objective, scenario, architecture, setup, failure injection, troubleshooting path, remediation, validation, receipt requirements, repository plan, README outline, interview talking points, and extensions.

## Safeguards

Do not disguise a tutorial as production experience, require expensive infrastructure without need, create a failure with only one obvious copied solution, omit evidence/validation, or overstate what the lab proves.

## Sol optimization

Emphasize reproducible setup, automation, failure injection, commands, tests, observability, recovery, and evidence artifacts.

## Fable optimization

Emphasize learner journey, portfolio presentation, narrative clarity, diagrams, documentation usability, and how a reviewer experiences the project.
