# Prompt Generation Brief

## Purpose

Create a reusable prompt that converts transcripts, articles, PDFs, notes, and mixed sources into durable, reusable project knowledge.

## Required behavior

Identify central claims; separate source assertions from established facts; preserve useful nuance; map supporting evidence/source locations; identify unsupported/promotional/weak claims; surface disagreements/contradictions; extract methods, principles, examples, terminology, and actionable implications; connect findings to the current project; produce a reusable source note; preserve citations while avoiding excessive quotation.

## Inputs

One or more sources, source metadata, intended downstream use, project context, existing notes, and desired output format.

## Outputs

Executive distillation, claim-and-evidence map, durable principles, actionable methods, examples, disagreements/uncertainty, project implications, reusable source note, and suggested downstream tasks.

## Safeguards

Do not flatten disagreements, produce only a generic summary, present promotional claims as fact, lose citation context, overquote copyrighted material, or leave inferred implications unlabeled.

## Sol optimization

Emphasize technical mechanisms, reproducible procedures, architecture implications, implementation opportunities, and structured extraction.

## Fable optimization

Emphasize conceptual synthesis, memorable framing, narrative clarity, reader usefulness, and how the material can strengthen teaching or publication.
