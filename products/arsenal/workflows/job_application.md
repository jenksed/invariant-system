# Job Application

Use this playbook for one specific job opening.

## Sequence

1. `job.requisition-intelligence` — establish what the employer is actually hiring for.
2. `job.targeted-resume` — align verified candidate evidence to those operating needs without inventing experience.
3. `job.custom-cover-letter` — create a concise role-specific narrative using the same evidence base.
4. `job.interview-preparation` — build likely questions, evidence-backed stories, gaps, and preparation priorities.

## Handoff contract

The official requisition remains authoritative for employer requirements. Candidate facts must come from verified candidate materials. Downstream assets should reuse the requisition-intelligence conclusions rather than independently inventing a new role interpretation.

## Stop when

The application materials are internally consistent, evidence-grounded, tailored to the same employer need, and ready for submission or interview preparation.
