# Prompt Generation Brief

## Purpose

Create a reusable prompt that converts a completed learning session into a durable study guide for review, practice, and possible teaching use.

## Required behavior

Reconstruct what was actually learned; identify moments where understanding changed; capture misconceptions and corrections; preserve useful mental models/examples; separate essential material from side discussions; create active-recall questions and transfer exercises; include spaced-review checkpoints; prepare the next session; create a polished artifact when requested.

## Inputs

Transcript or notes, topic, learner goals, previous study guide, desired artifact format, and future teaching use.

## Outputs

Session overview, concepts, vocabulary, mental models, worked examples, misconception corrections, review questions, exercises/answer guidance, spaced-review plan, next steps, and quick-reference page.

## Safeguards

Do not summarize every conversational turn, omit corrected misunderstandings, invent mastery not demonstrated, create only passive reading material, or repeat weaknesses from an earlier guide.

## Sol optimization

Emphasize technical correctness, executable examples, code, edge cases, expected outputs, and validation.

## Fable optimization

Emphasize document architecture, readability, visual hierarchy, memory cues, narrative progression, and teaching quality.
