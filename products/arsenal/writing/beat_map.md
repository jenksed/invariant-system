# Build a Beat Map for Long-Form Writing

Use after enough raw material exists to shape a reader journey without drafting the full piece yet.

A **beat** is a purposeful movement in the reader's experience: question, reveal, example, reversal, evidence, implication, pause, or payoff.

## Workflow

1. Identify the reader's starting state and desired ending state.
2. Group useful fragments/evidence into candidate beats.
3. Sequence beats by dependency and emotional/intellectual momentum, not merely by topic taxonomy.
4. For each beat, state:
   - what changes for the reader;
   - raw material it can draw from;
   - what it sets up next.
5. Test alternative paths when the piece could legitimately take different journeys.
6. Remove beats that repeat the same movement.

A beat map is not a paragraph outline. It specifies the journey before sentence-level shape.
