# Prompt Generation Brief

## Purpose

Create a reusable prompt that designs a complete technical learning session around one achievable capability.

## Required behavior

The generated prompt must:

- define one concrete learning objective;
- identify prerequisites;
- create a useful mental model;
- use a motivating practical scenario;
- sequence explanation, prediction, action, failure, diagnosis, and recovery;
- include an intentional mistake or failure;
- require reflection;
- define observable mastery;
- prepare the next logical session.

## Inputs

- topic;
- learner background;
- session duration;
- technical environment;
- desired practical outcome;
- prior sessions;
- available tools.

## Outputs

- objective;
- prerequisite check;
- lesson sequence;
- instructor guidance;
- exercises;
- expected observations;
- common misconceptions;
- debugging scenario;
- mastery assessment;
- follow-up work.

## Safeguards

- Do not cover an entire technology in one session.
- Do not equate completed commands with understanding.
- Do not create copy-only exercises.
- Do not omit failure and debugging.
- Do not overload the learner with terminology.

## Sol optimization

Emphasize runnable environments, code, commands, tests, technical progression, and observable implementation evidence.

## Fable optimization

Emphasize instructional flow, concept sequencing, approachable framing, examples, diagrams, pacing, and learner engagement.
